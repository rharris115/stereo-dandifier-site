Multi-Picture

Reads files that each hold a complete picture for either eye — the MPO files of the Fujifilm FinePix REAL 3D cameras. Nothing is cut: each file is one pair.

Which files come here

The loader is made automatically when a file of a format and camera that no loader serves holds two or more pictures. It then takes every staged file of that format and camera.

A file is counted on the badge once it has been examined in the background: green in good order, amber with a warning, red if it cannot be read. See Badges and Marks.

Actions

  • Unstage All — withdraws its files from the collection; the loader goes with them.
