Text & Order

Gives the pairs their words and puts them in order. It feeds only layouts — Side-by-Side, Anaglyph and Stereo Card — and a layout takes the words of one Text & Order node at most. Nothing here touches the pictures, so no measurement after it is put out of date.

Caption, for each pair

Each pair's own caption, styled as the operator pleases. It belongs to the picture, so it is the same by whatever route the pair arrives. A pair without one is marked with a warning.

Fill Blanks writes every empty caption from its picture with Apple Intelligence (which must be turned on in System Settings).

Card ends and number

The same for every pair, and saved with the workflow — what a publisher printed on every card of a series:

  • Left and right end texts — set along each end of a card.
  • Number — the typeface and style of each pair's number. Where it is printed, if at all, is chosen in each layout.

Order

Pairs go on in the order of their taking, earliest first, unless moved by hand. Every node after this one lists them in this order, and Export… writes them in it. Sort by Time restores the order of taking.
