Spatial Photo

Reads spatial photographs: the HEIC files of the Apple Vision Pro, and of the iPhones that take spatial photos. Each file holds a complete picture for either eye and states which is which; that statement is followed, whatever order the pictures lie in. Nothing is cut.

Which files come here

The loader is made automatically when a file of a format and camera that no loader serves names its left and right pictures. It then takes every staged file of that format and camera.

A file is counted on the badge once it has been examined in the background: green in good order; red if it cannot be read, if its two pictures differ in height, or if it is an ordinary photograph from the same camera, naming no eyes. See Badges and Marks.

The disparity adjustment

A spatial photograph also records the camera's advice on how far apart its pictures should be set when shown in a window on the Vision Pro. It is not applied here: the pictures pass on exactly as taken.

Actions

  • Unstage All — withdraws its files from the collection; the loader goes with them.
