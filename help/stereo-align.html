Stereo Align

Removes the misalignments between a pair's eyes that make it uncomfortable to view, while keeping its depth:

  • Vertical offset — one eye standing higher than the other.
  • Roll — one eye turned against the other.
  • Scale — one eye slightly larger, as when a single camera is brought a little nearer between exposures.

It never shifts one eye sideways against the other, for that sideways difference is the depth. Keystone distortion, from cameras toed in, it does not correct.

How it measures

It follows every detail from one eye to the other and fits the three corrections to how far each moves up or down, since in a perfect pair nothing moves vertically. The fit is robust, so moving objects, reflections and plain surfaces do not mislead it. The correction is shared equally between the eyes, which are then cropped to the area they share.

Beside the correction it reports the pair's disparity of the infinity points, the depth the pair holds, as a share of its width; 3.3% is the customary maximum for comfortable viewing. It alters nothing.

Measuring takes a moment, so it is done only when asked: Align for the selected pair, Align All for every pair. A measurement is kept with the collection, and falls out of date the moment anything before this node is altered for that pair.

Settings for each pair

  • Reset — the pair passes through unaligned.

Where it goes

After Defish, if used; before Level, so that it measures the pair as the camera took it; and before Stereo Colour Match, so that only what both eyes see is compared.

Actions

  • Align All — measures every pair afresh, reset or not.
  • Reset All — sets every pair to no correction.
