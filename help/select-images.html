Select Images

Chooses which pairs go on to the nodes after it: tick those to be passed on. The pictures pass through untouched. Pairs left out are counted grey on its badge; see Badges and Marks.

Several may be used to send different pairs down different branches — some to an anaglyph, others to stereo cards.

Actions

  • Select All — every pair is passed on.
  • Select None — no pair is passed on.
